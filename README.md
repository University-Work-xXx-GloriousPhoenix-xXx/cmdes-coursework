# Курсова робота

| **Номер завдання** | **Формалізм** |
|---|---|
| B10 | Петрі-об'єктна мережа |

## Опис завдання

> &emsp;Магістральний канал передачі даних складається із загального накопичувача та двох каналів – **основного** і **резервного**. Повідомлення надходять в систему через **9 ± 5 с** і чекають в накопичувачі передачі.
>
> &emsp;У нормальному режимі роботи повідомлення передаються по основному каналу за **7 ± 3 с**. В основному каналі через інтервали часу **200 ± 35 с** трапляються збої. Якщо збій трапляється під час передачі повідомлення, то відбувається його переривання.
>
> &emsp;При цьому за **2 с** запускається резервний канал, який передає повідомлення з самого початку. Відновлення основного каналу займає **70 ± 7 с**. До відновлення основного каналу повідомлення передаються по резервному каналу. Після відновлення резервний канал відключається і основний канал продовжує роботу із чергового повідомлення.
>
> &emsp;Прибуток від передачі одного повідомлення через основний канал складає **50 грошових одиниць**, а при передачі через резервний канал – **25 грошових одиниць**.
>
> &emsp;Існує можливість підвищити надійність роботи основного каналу. При збільшенні середнього часу напрацювання на відмову на **k секунд** прибуток з кожного повідомлення зменшується на **0,03k грошових одиниць**.

## Вхідні параметри

| Параметр | Значення |
|---|---|
| Інтервал надходження повідомлень | 9 ± 5 с |
| Час передачі основним каналом | 7 ± 3 с |
| Інтервал між збоями основного каналу | 200 ± 35 с |
| Час запуску резервного каналу | 2 с |
| Час відновлення основного каналу | 70 ± 7 с |
| Прибуток (основний канал) | 50 у.о. / повідомлення |
| Прибуток (резервний канал) | 25 у.о. / повідомлення |
| Плата за надійність | −0,03k у.о. з кожного повідомлення при +k с до напрацювання на відмову |

## Що потрібно визначити

1. Найкращий режим роботи системи (оптимальне значення **k**).
2. Завантаження основного та резервного каналів.
3. Частоту переривання повідомлень.
4. Статистичні характеристики часу передачі повідомлень по магістралі.
